# Icon sources

`youtube-icon-red.png` is the unmodified `YouTube_Icon/Digital/01 Red/yt_icon_red_digital.png`
from YouTube's official core icon download, retrieved on 21 October 2026.

- Guidance: https://brand.youtube/youtube-icon/
- Download: https://www.gstatic.com/marketing-cms/78/29/3e68a1414bb28d0b7e47b44c3c91/youtube-icon.zip

The PNG includes transparent clear space. The homepage preserves that space,
the original proportions and red/white colours. The image is part of the channel
link and follows the address; the full YouTube wordmark is not used.
